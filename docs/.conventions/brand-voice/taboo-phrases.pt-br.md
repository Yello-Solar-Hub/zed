# Expressões tabu

Esses padrões indicam textos gerados por IA ou com forte viés de marketing. Elimine todas as ocorrências.

---

## Padrões estruturais de IA

Essas construções revelam que o texto foi escrito por uma IA:

### Cadeias de travessões

```
❌ "Zed is fast — really fast — and it shows in every interaction."
✅ "Zed is fast. You'll feel it in every interaction."
```

### "Não é X, é Y"

```
❌ "It's not just an editor — it's a complete development environment."
✅ "Zed combines editing, collaboration, and AI assistance in one workspace."
```

### Listas paralelas triplas

```
❌ "Fast. Focused. Collaborative."
❌ "Write code. Ship faster. Stay in flow."
✅ "Zed is built for speed and collaboration."
```

### Listas introduzidas por dois pontos em prosa

```
❌ "Three things make Zed different: speed, collaboration, and AI."
✅ "Zed prioritizes speed, real-time collaboration, and AI integration."
```

### Perguntas retóricas como forma de iniciar uma conversa

```
❌ "What if your editor could keep up with your thinking?"
✅ "Zed renders every keystroke instantly."
```

## Entusiasmo vazio

Elimine toda a manipulação emocional:

| Padrão                           | Problema                          |
| --------------------------------- | -------------------------------- |
| "Estamos muito animados em anunciar..."    | Ninguém se importa com suas emoções |
| "Estamos muito animados em compartilhar..."      | O mesmo                             |
| "Mal podemos esperar para que você experimente..." | Presunçoso                     |
| "Você vai adorar..."                  | Dizer ao leitor como se sentir       |
| "Prepare-se para..."                 | Exagero de marketing                   |
| "Diga adeus a..."               | Configuração clichê                     |
| "Diga 'olá' para..."                 | Continuação do clichê                  |
| "Finalmente, um editor que..."      | Isso significa que todos os outros falharam        |
| "A espera acabou"                | Presume antecipação            |
| "Apresentando..." (como texto independente)  | Começo fraco                      |

## Benefícios vagos

Substitua por resultados específicos:

| Vago                   | Pergunte, em vez disso                    |
| ----------------------- | ------------------------------ |
| "maior produtividade" | Quanto mais rápido? Em qual tarefa? |
| "fluxo de trabalho aprimorado"     | Que melhoria específica?     |
| "melhor experiência"     | Melhor em que sentido? É mensurável?        |
| "processo simplificado"   | Quais etapas foram removidas?       |
| "desempenho otimizado" | Qual métrica melhorou?          |
| "maior eficiência"  | O que exige menos tempo/esforço?   |
| "desenvolvimento moderno"    | Que capacidade específica?      |
| "programação de nível avançado"     | Sem sentido                    |
| "qualidade superior"      | Com base em que critério?               |

## Pontuação proibida

| Padrão     | Regra                               |
| ----------- | ---------------------------------- |
| `!`         | Nunca. Zero pontos de exclamação.    |
| `...`       | Sem reticências dramáticas               |
| TODAS EM MAIÚSCULAS    | Não grite para dar ênfase           |
| `?` como gancho | Nada de perguntas retóricas como introdução |
| `—` uso excessivo | No máximo um travessão por parágrafo      |

## Eufemismos corporativos

| Frase              | Problema                       |
| ------------------- | ----------------------------- |
| fazer a diferença     | Jargão                        |
| sinergia             | Empresa do nível dos memes           |
| ecossistema           | Muitas vezes sem sentido             |
| mudança de paradigma      | Palavra da moda ultrapassada                |
| abordagem holística   | Vago                         |
| solução escalável   | Que escalas? Como?             |
| insights que podem ser colocados em prática | Jargão corporativo               |
| proposta de valor   | Nunca em textos voltados para o cliente |
| alavancar (verbo)     | Use “use” em vez disso             |
| utilizar             | Use “use” em vez disso             |
| facilitar          | Use um verbo mais claro              |
| capacitar             | Condescendente                   |
| ativar              | Muitas vezes é vago; seja específico      |

## Expressões de preenchimento

Excluir sem substituir:

- "No mundo acelerado de hoje..."
- "Como desenvolvedores, sabemos que..."
- "Vamos admitir..."
- "A verdade é que..."
- "No fim das contas..."
- "Quando se trata de..."
- "A fim de..."
- "Não é preciso dizer que..."
- "Não preciso nem dizer que..."
- "Como vocês devem saber..."

---

## Lista de verificação para detecção

Antes de finalizar, verifique se há:

1. **Superlativos:** melhor, mais, mais rápido, único, primeiro, definitivo
2. **Termos absolutos:** sempre, nunca, todo, todos, completamente, totalmente
3. **Expressões de cautela:** talvez, poderia, potencialmente, possivelmente, pode ajudar
4. **Intensificadores:** muito, realmente, extremamente, incrivelmente, absolutamente
5. **Quantificadores vagos:** muitos, numerosos, significativos, substanciais

**Regra:** Se você não puder provar ou medir, reescreva.

---

## Referência rápida

**Sinais de alerta imediatos (reprovação automática se estiverem presentes):**

- Qualquer ponto de exclamação
- "Estamos animados/empolgados"
- "Revolucionário" ou "que muda o jogo"
- O travessão longo usado mais de duas vezes em um parágrafo
- A construção “Não é X, é Y”

**Bandeiras amarelas (analise com cuidado):**

- Alguma palavra da lista “Hype Words”?
- Frases que começam com “E” ou “Mas”
- Perguntas nos títulos
- Listas com exatamente três itens
