# Guião de Avaliação da Voz da Marca

Avalie cada critério com uma nota de 1 a 5. O texto deve obter **nota 4 ou mais em TODOS os critérios** para ser aprovado.

---

## 1. Fundamentos técnicos (1-5)

O texto apresenta alegações técnicas específicas e verificáveis?

| Pontuação | Descrição                                                                               |
| ----- | ----------------------------------------------------------------------------------------- |
| 5     | Detalhes técnicos precisos que possam ser verificados (especificações, arquitetura, resultados mensuráveis) |
| 4     | Afirmações técnicas concretas com significado claro                                              |
| 3     | Mistura de referências técnicas específicas e vagas                                            |
| 2     | Predominantemente abstrato, com termos técnicos ocasionais                                           |
| 1     | Sem conteúdo técnico; pura linguagem de marketing                                           |

**Exemplos:**

- ✅ “Desenvolvido em Rust com renderização acelerada por GPU a 120 fps”
- ❌ “Desempenho extremamente rápido que vai transformar seu fluxo de trabalho”

---

## 2. Sintaxe natural (1-5)

A redação flui como a fala natural de um desenvolvedor atencioso?

| Pontuação | Descrição                                                     |
| ----- | --------------------------------------------------------------- |
| 5     | Estrutura variada das frases, ritmo natural, leitura em voz alta fluida |
| 4     | Em geral, soa natural, com pequenos problemas de ritmo                         |
| 3     | Alguns padrões de IA são visíveis, mas não predominantes                       |
| 2     | Padrões estruturais evidentes (tríades paralelas, cadeias de travessões longos) |
| 1     | Cadência robótica, construção estereotipada do início ao fim              |

**Sinais de alerta:** uso excessivo do travessão, construções do tipo “Não é X, é Y”, listas paralelas triplas, frases todas com o mesmo comprimento.

---

## 3. Confiança serena (1-5)

O texto apresenta fatos sem exageros nem manipulação emocional?

| Pontuação | Descrição                                              |
| ----- | -------------------------------------------------------- |
| 5     | Os fatos falam por si; o leitor tira suas próprias conclusões |
| 4     | Afirmações confiantes, sem floreios desnecessários               |
| 3     | Há certa moderação, mas, de vez em quando, surge um certo exagero             |
| 2     | Uso frequente de superlativos ou apelos emocionais               |
| 1     | Tom de marketing agressivo, que dita ao leitor como deve se sentir    |

**Exemplos:**

- ✅ “O Zed renderiza cada quadro na GPU. Você vai notar a diferença ao rolar a tela.”
- ❌ “Experimente a velocidade revolucionária que vai transformar completamente a maneira como você programa!”

---

## 4. Respeito aos desenvolvedores (1-5)

O texto trata o leitor como um colega, e não como um cliente em potencial?

| Pontuação | Descrição                                             |
| ----- | ------------------------------------------------------- |
| 5     | Conversa entre pares; pressupõe conhecimento técnico |
| 4     | Respeitoso e com o nível adequado de profundidade técnica             |
| 3     | Um pouco condescendente ou simplista demais                  |
| 2     | Explicações condescendentes ou entusiasmo forçado         |
| 1     | Trata o leitor como um consumidor desinformado que precisa ser convencido    |

**Exemplos:**

- ✅ “O Tree-sitter oferece análise incremental, de modo que o realce de sintaxe é atualizado à medida que você digita.”
- ❌ “Não se preocupe com os detalhes técnicos — basta saber que é rápido!”

---

## 5. Prioridade da informação (1-5)

A informação mais importante vem primeiro?

| Pontuação | Descrição                                         |
| ----- | --------------------------------------------------- |
| 5     | Fatos-chave ou mudanças determinantes; o contexto surge naturalmente |
| 4     | Informações importantes no início da página, com uma breve introdução         |
| 3     | A notícia principal está escondida, mas é possível recuperá-la                         |
| 2     | Grande expectativa antes do conteúdo                |
| 1     | Informações importantes ocultas ou totalmente ausentes          |

**Exemplos:**

- ✅ “Agora, as sugestões em tempo real são exibidas token por token. Antes, era preciso esperar pela resposta completa.”
- ❌ “Temos refletido bastante sobre a experiência do desenvolvedor e, após meses de trabalho, estamos muito animados em compartilhar que...”

---

## 6. Especificidade (1-5)

As alegações são concretas e mensuráveis?

| Pontuação | Descrição                            |
| ----- | -------------------------------------- |
| 5     | Cada alegação é específica e verificável |
| 4     | Predominantemente específico, com raras abstrações |
| 3     | Uma mistura de alegações concretas e vagas       |
| 2     | Benefícios, em sua maioria, abstratos               |
| 1     | Todas as alegações são vagas ou não podem ser comprovadas   |

**Exemplos:**

- ✅ “Tempo de inicialização inferior a 100 ms em Macs com M1”
- ❌ “Inicialização ultrarrápida que respeita o seu tempo”

---

## 7. Consistência da voz (1-5)

O tom permanece uniforme ao longo de todo o texto?

| Pontuação | Descrição                                |
| ----- | ------------------------------------------ |
| 5     | Uma voz única e coerente do início ao fim |
| 4     | Pequenas variações tonais que não distraem     |
| 3     | Desvio perceptível entre as seções          |
| 2     | Várias vozes em conflito                  |
| 1     | Inconsistência tonal chocante                |

**Verifique se há:** Mudanças entre tom informal/formal, técnico/de marketing, confiante/cauteloso.

---

## 8. Reclamações devidas (1-5)

As afirmações são comprovadas ou podem ser comprovadas?

| Pontuação | Descrição                                 |
| ----- | ------------------------------------------- |
| 5     | Toda afirmação pode ser comprovada ou verificada |
| 4     | As alegações são razoáveis e, em sua maioria, verificáveis |
| 3     | Algumas afirmações sem fundamento                 |
| 2     | Vários superlativos não verificáveis          |
| 1     | Afirmações ousadas sem fundamento                 |

**Exemplos:**

- ✅ “Desenvolvido pela equipe responsável pelo Atom e pelo Tree-sitter”
- ❌ “O editor mais avançado já criado”

---

## Modelo de pontuação rápida

```
| Criterion           | Score | Notes |
|---------------------|-------|-------|
| Technical Grounding |   /5  |       |
| Natural Syntax      |   /5  |       |
| Quiet Confidence    |   /5  |       |
| Developer Respect   |   /5  |       |
| Information Priority|   /5  |       |
| Specificity         |   /5  |       |
| Voice Consistency   |   /5  |       |
| Earned Claims       |   /5  |       |
| **TOTAL**           |  /40  |       |

Pass threshold: 32/40 (all criteria 4+)
```

---

## Regras de decisão

- **Todos 4+:** Revisão do texto. Pequenos ajustes opcionais.
- **Qualquer uma das 3 opções:** Reescrever as seções sinalizadas e refazer a avaliação.
- **Qualquer nota 2 ou inferior:** É necessária uma reconstrução completa.
- **Várias falhas:** Comece do zero com uma nova abordagem.
