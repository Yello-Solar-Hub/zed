# Paleta de comandos

A Paleta de Comandos é a principal forma de acessar as ações no Zed. Sua combinação de teclas é um dos primeiros atalhos a serem aprendidos: {#kb command_palette::Toggle}.

![A Paleta de Comandos aberta](https://zed.dev/img/features/command-palette.jpg)

Para experimentar, abra a Paleta de Comandos e digite `new file`. A lista de comandos deve ser filtrada para {#action workspace::NewFile}. Pressione Return para criar um novo buffer.

Sempre que você encontrar instruções que incluam comandos do tipo `zed: ...` ou `editor: ...` e assim por diante, isso significa que você precisa executá-los na Paleta de Comandos.
